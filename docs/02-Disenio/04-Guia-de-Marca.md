# 🎨 04 - Lineamientos de Marca y Paleta de Colores

Este documento define la identidad visual, tokens CSS, componentes estandarizados y tipografías oficiales de **Cigarrería Megalider**.

---

## 🎨 Paleta de Colores Oficial

| Tono / Rol | Código Hex | Aplicación en la Interfaz |
| :--- | :--- | :--- |
| **Verde Esmeralda Oscuro** | `#067335` | Color primario, logotipos, títulos serif y barras principales. |
| **Verde Acción (CTA)** | `#038C3E` | Botones de acción principal (`Button variant="primary"`), estados activos. |
| **Verde Medio** | `#53A677` | Bordes sutiles, detalles de branding y líneas secundarias. |
| **Menta Suave** | `#A7D9BD` | Badges de estado (`Badge variant="mint"`), fondos de iconos y acentos. |
| **Fondo Claro / Neutro** | `#F2F2F2` | Fondo de página general, tarjetas secundarias y contraste limpio. |

---

## ✒️ Tipografía Institucional

1. **Títulos y Encabezados (Serif):** `Playfair Display`
   - Aplicación: Títulos principales `<h1>`, `<h2>`, logotipos y encabezados de tarjetas destacadas.
2. **Textos e Interfaz (Sans-Serif):** `Plus Jakarta Sans`
   - Aplicación: Cuerpo de texto, botones, tablas de datos, inputs y elementos interactivos.

---

## 🧩 Componentes del Design System UI

* **`Button`:** Variantes `primary` (`#038C3E`), `secondary`, `outline`, `ghost`, `danger`.
* **`Card`:** Tarjetas contenedoras con bordes finos `#53A677` y sombreado suave.
* **`Badge`:** Etiquetas de estado (`mint`, `warning`, `success`, `danger`).
* **`Input`:** Campos de formulario con foco personalizado en verde primario `#067335`.

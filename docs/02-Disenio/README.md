# 02 - Documentos de Diseño y Arquitectura

Este módulo agrupa la arquitectura conceptual y física del sistema, los modelos de datos, los diagramas de secuencia de autenticación, los lineamientos visuales de la marca y los patrones de software aplicados en **Cigarrería Megalider**.

---

## 📑 Contenido del Módulo

1. 🏛️ [**01 - Arquitectura General del Sistema**](./01-Arquitectura-General.md): Diagrama Mermaid de la arquitectura de capas, integración Multi-BD (PostgreSQL + MySQL) y flujo del bot Hermes IA.
2. 🗄️ [**02 - Modelo de Datos (Diagrama ER)**](./02-Modelo-de-Datos.md): Diagrama Entidad-Relación (Mermaid ER) y tablas de usuarios, catálogo, facturas y auditoría.
3. 🔄 [**03 - Flujos de Autenticacion (OAuth 2.0 + RBAC)**](./03-Flujos-de-Autenticacion.md): Diagrama de secuencia Mermaid para Google OAuth 2.0, cookies de seguridad y Middleware Edge RBAC.
4. 🎨 [**04 - Guia de Marca y Sistema de Disenio**](./04-Guia-de-Marca.md): Paleta de colores oficial en Hex, tipografía institucional y especificación de componentes UI.
5. 🛡️ [**05 - Patrones de Arquitectura y Estado**](./05-Patrones-de-Arquitectura.md): Patrones DAL (server-only), Cache Components, BFF, Lazy Loading, Web Vitals y Zustand.

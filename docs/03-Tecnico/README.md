# 03 - Manual Técnico e Instrucciones de Instalación

Este módulo constituye el manual técnico completo del sistema, abarcando las especificaciones del stack, la configuración de variables de entorno, Google OAuth 2.0, API Route Handlers, seguridad JWT, instrumentación Web Vitals y el módulo de contabilidad.

---

## 📑 Contenido del Módulo

1. 🛠️ [**01 - Stack Tecnológico y Configuración**](./01-Stack-y-Configuracion.md): Versiones de dependencias, variables `.env.local`, configuración Google Cloud Console e instrucciones de ejecución.
2. 🌐 [**02 - Endpoints de API y Backend for Frontend (BFF)**](./02-Endpoints-y-BFF.md): Especificación de endpoints OAuth 2.0, resolución de parámetros asíncronos y manual de Route Handlers.
3. 🔒 [**03 - Seguridad, Sesiones y Middleware Edge**](./03-Seguridad-y-Sesiones.md): Algoritmos de firma JWT (`jose`), cookies HttpOnly, prevención CSRF y middleware Edge RBAC.
4. ⚡ [**04 - Estándares Next.js 16+, Rendimiento y Estado**](./04-Estandares-Nextjs-y-Rendimiento.md): Cache Components, Suspense, Lazy Loading, instrumentación Web Vitals y Zustand stores.
5. 📄 [**05 - Módulo de Contabilidad y Facturas de Compra**](./05-Modulo-Contabilidad.md): Arquitectura de facturas, recálculo en tiempo real en PostgreSQL y modales de edición.
6. 🤖 [**06 - Estándares de Agentes IA y Skills Indexadas**](./06-Agentes-y-Skills.md): Estándares de desarrollo para agentes IA y directivas de eficiencia de contexto.

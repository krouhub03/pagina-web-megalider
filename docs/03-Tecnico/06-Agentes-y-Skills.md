# 🤖 06 - Estándares de Agentes IA y Skills Indexadas

El proyecto cuenta con un ecosistema de directivas especializadas (skills) para guiar el desarrollo asistido por IA, garantizando un código limpio, optimizado y alineado con los estándares del proyecto.

---

## 🤖 Directivas y Skills Indexadas

* **Directivas de Contexto:** Código modular, reducción de ruido sintáctico, tipado estricto con TypeScript 5+.
* **Skills Indexadas en `.agents/skills/`:**
  - [`nextjs-coding`](../../.agents/skills/nextjs-coding/SKILL.md): Estándares de desarrollo para Next.js 16+ (App Router).
  - [`megalider-brand`](../../.agents/skills/megalider-brand/SKILL.md): Paleta de colores, tipografías y reglas de marca.
  - [`token-optimization`](../../.agents/skills/token-optimization/SKILL.md): Estrategias de eficiencia de contexto.
  - [`nextjs-analytics`](../../.agents/skills/nextjs-analytics/SKILL.md): Instrumentación de Core Web Vitals.
  - [`nextjs-lazy-loading`](../../.agents/skills/nextjs-lazy-loading/SKILL.md): Carga diferida de recursos y librerías.
  - [`nextjs-bff`](../../.agents/skills/nextjs-bff/SKILL.md): Arquitectura Backend for Frontend.
  - [`nextjs-unit-testing`](../../.agents/skills/nextjs-unit-testing/SKILL.md): Pruebas unitarias con Vitest y mocks.
  - [`nextjs-zustand`](../../.agents/skills/nextjs-zustand/SKILL.md): Estado cliente inmutable con Zustand.

# ⚡ 02 - Pruebas Unitarias Automatizadas

Este directorio documenta la suite de **64 pruebas unitarias automatizadas** del sistema, desarrolladas con **Vitest** y **React Testing Library**.

---

## ⚡ Estructura de Documentación de Pruebas Unitarias

1. 🎨 [**01 - Componentes UI & Autenticación**](./01-Componentes-UI.md): Pruebas de interfaz para `LoginPage.test.tsx` y `RegisterPage.test.tsx`.
2. 💼 [**02 - Servicios de Negocio**](./02-Servicios-y-Negocio.md): Pruebas de lógica de autenticación y validación de contraseñas/hash (`auth.service.test.ts`).
3. 🛠️ [**03 - Librerías y Utilidades**](./03-Librerias-y-Utilidades.md): Pruebas de tokens JWT (`jwt.test.ts`), reCAPTCHA (`recaptcha.test.ts`) y formateadores de moneda/fechas (`utils.test.ts`).
4. 🛒 [**04 - Stores de Zustand**](./04-Stores-Zustand.md): Pruebas de estado global inmutable (Carrito, Filtros, Verificación de Edad, Toast, QuickView, Auditoría).
